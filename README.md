# RAG Pipeline - Retrieval Augmented Generation
A production-ready RAG pipeline built Python LangChain,and Vector Databases.
## Features
Document ingestion (PDF,TXT,CSV)
Text chunking & embedding
Vectors search with ChraDB/FAISS
LLM-powered Q&A
Evaluation metrics
## Tech stack 
- Python 3.10+
- LangChain
- OpenAI / HuggingFace Embeddings
- ChrmaDB
- Streamlit UI
